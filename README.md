Файлы gd

ontrol.gd
Скрипт для построения визуальной гистограммы. Он рекурсивно сканирует указанную
 папку с документами, считает количество слов в каждом текстовом файле и строит 
столбчатую диаграмму (программно создаёт колонки с цветными столбиками, подписями
 с цифрами и тултипами при наведении мыши).

button.gd
Минималистичный скрипт для кнопки. При загрузке сам подключает свой сигнал
 pressed и при клике переключает сцену на res://scenes/next_scene.tscn.
node_2d.gd

Скрипт для узла Node2D. Находит в сцене дочернюю кнопку, вешает на неё обработчик
 и при нажатии перекидывает пользователя на сцену главного редактора (res://och.tscn).

contsrol.gd
Полноценное меню настроек редактора. Программно генерирует UI для выбора шрифта,
 его размера, цветовой темы, нумерации строк и автосохранения. 
Сканирует папки на наличие шрифтов (корректно обрабатывает 
.remap файлы, чтобы работать и в редакторе, и в скомпилированном .exe), 
сохраняет и читает конфиг из settings.cfg. Также содержит кнопки 
для открытия папок с файлами и шрифтами через системный проводник ОС.

och.gd
Главный скрипт самого текстового редактора. Управляет текстовым полем (CodeEdit):
 открывает, сохраняет файлы и отслеживает статус изменений. 
Применяет к редактору все настройки из конфига (темы, шрифты, 
переносы строк). Обрабатывает клики по 5 иконкам для открытия дополнительных
 вкладок-сцен (закладки, графы знаний и т.д.) и ловит горячие клавиши (
Ctrl+S для сохранения, Esc для возврата из вкладок обратно в редактор).

at-icons.gd
Плагин для самого редактора Godot (использует @tool).
 Добавляет кастомную боковую панель (док) с названием 
"@icons" в интерфейс редактора и подгружает в неё сцену для просмотра иконок.

sssconsatrol.gd
Главный экран управления документами
, стилизованный под Google Docs. Программно генерирует 
UI с шапкой и поиском, секцией создания пустого документа
 и сеткой «Недавних документов». Сканирует хранилище, сортирует 
файлы по дате изменения, фильтрует их по поиску и открывает по двойному клику.

information_4.gd
Скрипт для визуализации статистики 
. Рекурсивно обходит папку с документами, с
читает количество слов в каждом файле и строит 
столбчатую диаграмму (гистограмму), 
где высота столбца пропорциональна объёму текста.

file_panel.gd
Панель файлового менеджера (дерево файлов). 
Отображает иерархию папок и файлов в хранилище, 
позволяет создавать новые файлы и папки через
 контекстное меню (по правому клику мыши) и отправляет сигнал 
в основной редактор для открытия файла при двойном клике.
