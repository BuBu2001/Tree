# OCH (Experimental Text Editor)

> **Статус проекта:** Экспериментальный  
> **Текущая версия:** v0.5 (Разработка v1 ведётся)

## 📌 Описание
OCH — это экспериментальный текстовый редактор, разрабатываемый на движке Godot. Проект ориентирован на управление знаниями, визуализацию статистики документов и предоставление удобного интерфейса для работы с текстом, включая кастомизацию и навигацию по графам знаний.

## 🏗 Структура сцен
Основные модули и сцены проекта:
1. **onif** — Настройки.
2. **bookmarks** — Закладки.
3. **knowledge** — База всех ранее созданных документов.
4. **information** — Диаграмма (визуализация статистики).
5. **graph** — Граф знаний.

## 📂 Описание скриптов (`.gd`)

| Файл | Описание |
| :--- | :--- |
| `control.gd` *(в исходнике: `ontrol.gd`)* | Скрипт для построения визуальной гистограммы. Рекурсивно сканирует указанную папку с документами, считает количество слов в каждом текстовом файле и программно строит столбчатую диаграмму (колонки с цифрами и тултипами при наведении). |
| `button.gd` | Минималистичный скрипт кнопки. При загрузке автоматически подключает свой сигнал `pressed` и при клике переключает сцену на `res://scenes/next_scene.tscn`. |
| `node_2d.gd` | Скрипт для узла `Node2D`. Находит в сцене дочернюю кнопку, вешает на неё обработчик и при нажатии перенаправляет пользователя на сцену главного редактора (`res://och.tscn`). |
| `settings_control.gd` *(в исходнике: `contsrol.gd`)* | Полноценное меню настроек редактора. Программно генерирует UI для выбора шрифта, его размера, цветовой темы, нумерации строк и автосохранения. Сканирует папки на наличие шрифтов (корректно обрабатывает `.remap`-файлы для работы как в редакторе, так и в скомпилированном `.exe`). Сохраняет и читает конфиг из `settings.cfg`. Содержит кнопки для открытия папок с файлами и шрифтами через системный проводник ОС. |
| `och.gd` | Главный скрипт текстового редактора. Управляет текстовым полем (`CodeEdit`): открывает и сохраняет файлы, отслеживает статус изменений. Применяет к редактору все настройки из конфига (темы, шрифты, переносы строк). Обрабатывает клики по 5 иконкам для открытия дополнительных вкладок-сцен и перехватывает горячие клавиши (`Ctrl+S` для сохранения, `Esc` для возврата из вкладок в редактор). |
| `at-icons.gd` | Плагин для самого редактора Godot (использует `@tool`). Добавляет кастомную боковую панель (док) с названием "@icons" в интерфейс редактора и подгружает в неё сцену для просмотра иконок. |
| `documents_control.gd` *(в исходнике: `sssconsatrol.gd`)* | Главный экран управления документами, стилизованный под Google Docs. Программно генерирует UI с шапкой и поиском, секцией создания пустого документа и сеткой «Недавних документов». Сканирует хранилище, сортирует файлы по дате изменения, фильтрует их по поиску и открывает по двойному клику. |
| `information_4.gd` | Скрипт для визуализации статистики. Рекурсивно обходит папку с документами, считает количество слов в каждом файле и строит столбчатую диаграмму (гистограмму), где высота столбца пропорциональна объёму текста. |
| `file_panel.gd` | Панель файлового менеджера (дерево файлов). Отображает иерархию папок и файлов в хранилище, позволяет создавать новые файлы и папки через контекстное меню (правый клик мыши) и отправляет сигнал в основной редактор для открытия файла при двойном клике. |

## 📂 План:
1. Реализовать "#" и [] и {}. - реализованно
Пояснение: # - поиск по хэштегу, задавание хэштега. 
[] Логика: [Название] <-> [Название]; в первом и во втором указываешь название
документа, например есть документ А и Б, в А указываешь [Б] в Б указываешь [А]
{} Логика: {[],[]}, то есть есть сеть из А и Б и В и Г, в А указываешь
 [Б] в Б указываешь [А], в В указываешь [Г], в Г указываешь [В], 
получается: [А] [Б] и [Г] [Д], теперь же ты хочешь комбинацию, {[Б],[Г]} или 
{[А],[Д]} - будет комбинация.
